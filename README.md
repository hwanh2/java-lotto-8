# java-lotto-precourse
## 우아한테크코스 프리코스 3주차 미션

---

## 기능목록

입력 요구사항
- 로또 구입 금액을 입력받는다.
  - [x] 금액은 1000원 단위로 입력 받으며 1000원으로 나누어 떨어지지 않으면 예외 처리한다.
- 당첨 번호를 입력받는다.
  - [ ] 당첨 번호는 쉼표를 기준으로 구분한다.
- 보너스 번호를 입력받는다.

기능 요구사항
- [x] 로또 번호의 숫자 범위는 1~45까지이다.
- [x] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
  - [x] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
  - [x] 로또 한 장의 가격은 1000원이다.
- [x] 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- [x] 당첨은 1등부터 5등까지이며 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- [ ] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.

예외 처리
- 모든 예외처리는 IllegalArgumentException, IllegalStateException과 같은 명확한 유형으로 처리하고 해당 부분부터 다시 입력받는다.
- [ ] 구입 금액이 숫자가 아니면 예외 처리한다.
- [ ] 구입 금액이 1000보다 작으면 예외 처리한다.
- [ ] 로또 번호, 보너스 번호 입력에 숫자가 아니면 예외 처리한다.
- [x] 중복된 번호를 입력하면 예외 처리한다.
